## Встановлення залежностей

```
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```


## Запустити детекцію на відео: 
```
python predict_video.py --input examples/input.mp4 --output examples/output.mp4

# Запустити зі стандартними вагами  для порівняння 
python predict_video.py --input examples/input.mp4 --output examples/output_default.mp4 --weights weights/yolo26n_default.pt

# Передати threshold  
--threshold 0.5
```


## Для запуску навчання:
```
# Запустити навчання (це перезапише поточні ваги моделі weigths/best.pt)
source .venv/bin/activate
python train.py

# можна передати необов'язковий параметр
--epochs 1
```

## Інформація про датасет
Готового датасету що підійшов би не знайшов, збирав сам, з сайтів Pexels, Wikimedia.  
Вийшло 182 фото і 396 птахів. Основа датасету - птахи в польоті, є менша частка птахів в іншому положенні, і в різній кількості, і на різному фоні. Робив акцент щоб модель не плутала птахів з одиничними об'єктами на рівномірному фоні, як віддалений корабель в морі, або літак. Попередня перевірка показує що модель їх не сплутує.  

Розмітка даних  
Розмічав прогнавши спочатку дані через модель, потім правив і додавав мітки в labelImg.  
Розподіл: 80% train, 20% val. Також фото без птахів потрапили в обидві частини датасету. 


## Проблеми з якими стикався
Перша спроба навчання була з завеликим learning rate, зі 100 епох навчання зупинилось після 31 тому що метрика не покращувалась. Зменшення lr до 0.0005 виправило навчання, по звіту видно що метрики покращуються.  

Друга проблема: в першій версії датасету не було даних без птахів. На перевірочних відео були хибні спрацювання, наприклад модель детектила не птаха а предмет на фоні. Повністю позбутись хибних спрацювань не вдалось, але тут можна регулювати поріг, через параметр threshold. Перевіряв на відео з літаком, наприклад ./examples/input3.mp4 - хибних спрацювань немає. 

## Отримані метрики на validation-вибірці
Валідаційний датасет на: 38 фото. Це мало, тому метрики шумні.  
Найкраща епоха 89 з 100. Видно що у моделі почалось перенавчання (overfitting). 
  
precision - 0.816  
recall - 0.738  
mAP50 - 0.831  
mAP50-95 - 0.642    
Повний лог навчання і графіки метрик можна подивитись в ./run_stats

Базова модель навчена на 80 класах. Тому на тестовому відео ./examples/input.mp4  модель "з коробки" детектить птахів іноді як літаки, або повітряні змії. При донавчанні це виправилось. 


## Можливі покращення
Збільшити датасет, і також урізноманітнити: потрібні фото з різними птахами, на різному фоні, і в різних позиціях. 
Основна проблема - хибні спрацювання, отже треба це враховувати при зборі даних. Тобто брати більше даних які схожі на кадри з відео.
